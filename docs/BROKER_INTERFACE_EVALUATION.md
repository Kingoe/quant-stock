# 券商接口评估

本文档记录券商接口接入前的评估结论。当前项目定位仍是个人 A 股多因子选股辅助系统，不做自动实盘交易。

## 1. 当前结论

当前阶段只允许评估券商接口，不接入真实交易通道，不保存券商账号密码，不发起真实下单。

即使后续所有条件通过，也只进入“人工小资金试点评审”，不直接进入自动交易。

## 2. 第一阶段允许能力

- 读取账户概览。
- 读取持仓。
- 读取委托和成交记录。
- 本地生成订单草稿。
- 人工确认后，由用户在券商客户端手动执行。

## 3. 第一阶段禁止能力

- 自动登录券商账户。
- 自动提交买入或卖出委托。
- 自动撤单。
- 保存交易密码、短信验证码、动态口令等敏感凭证。
- 绕过券商客户端或监管要求。
- 在模拟运行不足时进行小资金试点。

## 4. 准入检查

进入人工小资金试点评审前，至少需要满足：

- 模拟运行不少于 60 天。
- 模拟运行最大回撤不超过 15%。
- 最近运行没有失败记录。
- 通知渠道已经启用。
- 人工确认开关已经启用。
- 模拟交易流程已经验证通过。

后端提供 `evaluate_broker_readiness` 用于执行这些检查。该函数只返回是否允许进入人工试点评审，不返回自动交易就绪状态。

## 5. 后续接入建议

后续如果继续推进，应优先选择只读接口或导入导出能力：

1. 先做只读账户和持仓同步。
2. 再做本地订单草稿和人工确认流程。
3. 最后才评估是否需要半自动能力。

任何真实交易能力都必须新增独立任务、独立测试、独立风控文档，并再次确认项目约束。
