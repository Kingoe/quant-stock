# 更新日志

## 2026-05-10

- 新增回测 API 模块，支持获取回测概览和图表数据。
- 新增 get_backtest_summary 函数，获取回测核心指标（总收益、年化收益、最大回撤、夏普比率、换手率、胜率）。
- 新增 get_equity_curve 函数，获取净值曲线数据。
- 新增 get_drawdown_curve 函数，获取回撤曲线数据。
- 新增 portfolio_snapshots 表到 schema，用于存储组合快照。
- 新增 _load_portfolio_snapshots 辅助函数，从数据库加载组合快照。
- 新增 7 项回测 API 测试，覆盖空数据库返回默认值、遵循 API 约定和自定义无风险利率。
- 新增基准对比模块，支持与沪深 300、中证 500 等基准指数对比。
- 新增 calculate_benchmark_return 函数，计算基准收益率（当前指数 - 前一指数）/ 前一指数。
- 新增 calculate_cumulative_returns 函数，计算累计收益率序列。
- 新增 calculate_benchmark_cumulative_returns 函数，计算基准累计收益率，支持缺失日期处理。
- 新增 align_strategy_and_benchmark_dates 函数，对齐策略和基准日期。
- 新增 13 项基准对比测试，覆盖基准收益计算、累计收益率、日期对齐和边界条件。
- 新增绩效指标模块，支持计算策略绩效指标。
- 新增 PerformanceMetrics 数据结构，包含总收益率、年化收益率、最大回撤、夏普比率、换手率和胜率。
- 新增 DailyReturn 数据结构，包含日期、策略日收益率和基准日收益率。
- 新增 calculate_total_return 函数，计算总收益率。
- 新增 calculate_annual_return 函数，计算年化收益率。
- 新增 calculate_max_drawdown 函数，计算最大回撤。
- 新增 calculate_sharpe_ratio 函数，计算夏普比率（收益率均值 - 无风险利率）/ 标准差。
- 新增 calculate_turnover_rate 函数，计算换手率（买入 + 卖出）/（2 * 平均组合价值）。
- 新增 calculate_win_rate 函数，计算胜率（策略收益 > 基准收益的天数占比）。
- 新增 calculate_performance_metrics 函数，串联计算全部绩效指标。
- 新增 18 项绩效指标测试，覆盖总收益、年化收益、最大回撤、夏普比率、换手率、胜率和综合指标计算。
- 新增持仓和现金记账模块，支持投资组合状态管理。
- 新增 Portfolio 数据结构，包含现金余额和股票持仓，验证非负约束。
- 新增 Position 数据结构，包含股票代码、持股数、平均成本和市值。
- 新增 PortfolioSnapshot 数据结构，包含日期、现金、持仓列表和总价值。
- 新增 apply_trade 函数，应用交易到投资组合，更新现金和持仓。
- 新增 calculate_position_value 和 calculate_portfolio_value 函数，计算持仓市值和组合总价值。
- 新增 get_position_details 函数，获取持仓详情列表。
- 新增 create_snapshot 函数，创建投资组合快照。
- 新增 create_initial_portfolio 函数，创建初始投资组合。
- 新增 17 项组合记账测试，覆盖买入、卖出、连续交易、价值计算、快照和参数校验。
- 新增 A 股交易限制模块，支持按交易约束过滤订单。
- 新增 TradingConstraints 数据结构，配置 T+1、涨停、跌停、停牌等限制。
- 新增 TradingDayStatus 数据结构，表示交易日状态（涨停、跌停、停牌）。
- 新增 filter_orders_by_trading_constraints 函数，根据交易约束过滤订单。
- 交易约束规则：T+1 限制当日买入当日卖出，涨停日不能买入，跌停日不能卖出，停牌日不能交易。
- 支持禁用单个约束或全部约束，支持配置默认约束。
- 新增 get_default_trading_constraints 函数，返回 A 股默认交易约束。
- 新增 14 项交易限制测试，覆盖 T+1、涨停、跌停、停牌、正常交易、多约束、禁用约束和空输入。
- 新增交易成本模块，支持买入和卖出交易成本计算。
- 新增 TradingCost 数据结构，包含佣金率、最低佣金、印花税率和滑点率配置。
- 新增 TradeResult 数据结构，包含股票代码、动作、股数、原始价格、执行价格、佣金、印花税、总成本和净价值。
- 新增 calculate_trading_cost 函数，计算交易成本，支持买入、卖出场景。
- 交易成本规则：佣金 = 成交金额 * 佣金率（不低于最低佣金），印花税仅卖出收取，滑点影响执行价格。
- 新增 get_default_trading_cost 函数，返回 A 股默认交易成本配置（万分之三佣金、5 元最低、千分之一印花税、千分之一滑点）。
- 新增 11 项交易成本测试，覆盖买入、卖出、最低佣金、滑点、印花税、大额/小额交易和参数校验。
- 新增订单生成模块，支持根据目标仓位和当前持仓生成交易订单。
- 新增 Order 数据结构，包含股票代码、动作（买入/卖出）、股数和执行价格。
- 新增 generate_orders 函数，根据目标权重、当前持股、价格和组合价值生成订单。
- 订单生成规则：买入数量向下取整到 100 股，卖出数量四舍五入到 100 股，差异小于 50 股时不交易。
- 支持调仓场景、多股票场景，按股票代码排序输出。
- 新增 12 项订单生成测试，覆盖买入、卖出、调仓、100 股取整、小差异跳过、空输入、多股票、排序、参数校验、缺失价格处理和小于 50 股卖出。
- 新增周频调仓调度模块，支持按交易日历生成周频调仓日期。
- 新增 generate_weekly_rebalance_dates 函数，根据交易日历和指定调仓日（如周五）生成调仓日期列表。
- 新增 get_next_trade_date_after 函数，获取目标日期之后的第一个交易日。
- 调仓日期选择规则：选择 rebalance_day 指定的工作日，必须是开市日，按日期范围生成。
- 调仓日期按日期排序输出。
- 新增调仓调度测试，覆盖 Friday 选择、非交易日过滤、空数据处理、排序和下一个交易日查询。
