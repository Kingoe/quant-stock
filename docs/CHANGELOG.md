# 更新日志

## 2026-05-09

- 新增流动性因子计算模块，支持基于近 20 日平均成交额计算流动性因子得分。
- 新增 calculate_liquidity_factor 计算流动性因子，默认平均成交额权重为 1.0。
- 流动性因子使用评分日前近 20 日的日行情成交额，成交额越高得分越高。
- 对成交额历史不足 20 日的股票使用可解释的中性得分处理。
- 新增流动性因子测试，覆盖平均成交额排序、20 日窗口、权重配置和历史不足处理。
- 新增风险因子计算模块，支持基于波动率和最大回撤计算风险因子得分。
- 新增 calculate_risk_factor 计算加权风险因子，默认权重波动率 0.5、最大回撤 0.5。
- 风险因子使用评分日前 120 天内的日行情价格，优先使用 adjusted_close，缺失时回退使用 close_price。
- 最大回撤允许 0 作为有效低风险值，缺失价格历史时使用可解释的中性得分处理。
- 新增风险因子测试，覆盖低波动率排序、低最大回撤排序、权重配置、复权价格优先级和缺失价格历史处理。
- 新增动量因子计算模块，支持基于 60 日和 120 日涨跌幅计算动量因子得分。
- 新增 calculate_momentum_factor 计算加权动量因子，默认权重 60 日动量 0.5、120 日动量 0.5。
- 动量因子优先使用复权收盘价 adjusted_close，缺失时回退使用 close_price。
- 动量因子按评分日向前寻找可用价格，价格历史不足时使用可解释的中性得分处理。
- 新增动量因子测试，覆盖收益排序、权重配置、复权价格优先级和缺失价格历史处理。
- 新增成长因子计算模块，支持基于营收增速、净利润增速计算成长因子得分。
- 新增 calculate_growth_factor 计算加权成长因子，默认权重营收增速 0.5、净利润增速 0.5。
- 成长因子使用对齐后的财务数据，确保只使用评分日已披露的数据。
- 新增成长因子测试，覆盖成长排序、权重配置和财务数据对齐。
- 修复任务规划中 M4-2/M4-3 重复出现的问题，恢复按任务 ID 顺序推进的清晰状态。
- 运行 ruff format 修复后端代码和测试文件格式问题。
- 新增质量因子计算模块，支持基于 ROE、毛利率、现金流质量计算质量因子得分。
- 新增 calculate_quality_factor 计算加权质量因子，默认权重 ROE 0.4、毛利率 0.3、现金流质量 0.3。
- 新增 _calculate_cash_flow_quality 计算现金流质量（经营现金流 / 净利润）。
- 质量因子使用对齐后的财务数据，确保只使用已披露的数据。
- 新增质量因子测试，覆盖 ROE/毛利率/现金流质量排序、缺失数据处理、空值处理。
- 新增估值因子计算模块，支持基于 PE、PB、股息率计算估值因子得分。
- 新增 calculate_valuation_factor 计算加权估值因子，默认权重 PE 0.5、PB 0.3、股息率 0.2。
- 新增 _rank_values 归一化排名得分（0-1），支持正向和倒序排名。
- 估值因子使用对齐后的估值数据，确保只使用评分日已生效的数据。
- 新增估值因子测试，覆盖 PE/PB 倒序排名、股息率正序排名、缺失数据处理、空值处理。
- 新增因子输入数据对齐模块，确保只使用评分日已生效的数据。
- 新增 get_aligned_daily_price 获取评分日或之前最近交易日的日行情。
- 新增 get_aligned_valuation 获取评分日或之前最近估值日的估值数据。
- 新增 get_aligned_financial 获取评分日时已披露的最新财务数据，同时检查报告期和披露日期。
- 新增数据对齐测试，覆盖最新数据、最近日期、无数据、财务数据披露日期过滤等场景。
- 新增股票池查询 API 接口 /api/universe，支持按指数代码和调仓日期查询过滤后的股票池。
- 新增股票池查询 API 测试，覆盖基础过滤、全量过滤器、分页、空结果和 API 响应约定。
- API 支持配置参数：最小上市月数、最小平均成交额、最大 PE、最大 PB、页码、页大小。
- API 遵守 data + meta 响应约定，包含分页信息和时间戳。
- 新增估值异常过滤模块，支持从股票列表中过滤估值异常的股票，剔除负数、零或过大的 PE/PB，允许指标为 null，支持配置 PE/PB 上限。
